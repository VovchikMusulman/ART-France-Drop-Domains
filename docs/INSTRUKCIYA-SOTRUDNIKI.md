## 1. Назначение программы

**ART France — Drop Domains** — десктоп-приложение для подбора свободных (free) drop-доменов.

Программа помогает:
- найти топ‑5 конкурентов по поисковому запросу;
- собрать исходящие домены конкурентов;
- проверить, свободен ли домен;
- получить метрики (CheckTrust, Ahrefs DR и др.);
- разделить результаты на **Good** и **Bad**;
- сделать скриншоты исторических версий сайтов из Wayback Machine.

Установка Windows не требуется: достаточно одного файла `.exe`.

## 4. Первый запуск: Настройки

Перед работой откройте вкладку **Настройки** (справа в верхнем меню).

Ключи API и доступы выдаёт **руководитель**. Самостоятельно их создавать не нужно, если иное не указано.

📷 Скриншот 4: Вкладка «Настройки»

### 4.1. API поиска конкурентов

Выберите режим поиска в параметрах:
- **Serper (Google)** — нужен **Serper API key**
- **Yandex** — нужны **Yandex API key** и **Yandex Folder ID**, а также регион поиска

Вставьте выданные ключи в соответствующие поля. Сохранение происходит автоматически.

📷 Скриншот 5: Блок «API поиска конкурентов»

### 4.2. API сбора статистики

Заполните (по указанию руководителя):
- **CheckTrust API key** — метрики доменов (возраст, ИКС и др.)
- **Ahrefs API key (DR)** — Domain Rating (для режима Google)
- **Semrush** — email и пароль, затем подключение сессии (кнопка подключения в Настройках)

> Важно: не подключайте Semrush при каждом запуске без необходимости. Сессия сохраняется локально и переиспользуется. Частые логины могут заблокировать аккаунт.

📷 Скриншот 6: Блок «API сбора статистики» и Semrush

### 4.3. Параметры подсветки (пороги)

В Настройках задаются пороги подсветки «сильных» доменов в списке Good:
- режим **Google**: DR и AS;
- режим **Yandex**: возраст домена и ИКС.

Все **свободные** домены всё равно попадают в Good; пороги влияют на **подсветку**, а не на отбор free/занятых.

## 5. Перед поиском дропов: VPN с режимом TUN

Для сбора исходящих доменов программа использует **Semrush Outbound Domains**.  
Из РФ и санкционных территорий Semrush блокирует доступ. Без VPN поиск дропов **не сработает**.

### Обязательно перед нажатием «Найти дропы»

1. Включите корпоративный / рабочий **VPN**.
2. В настройках VPN включите режим **TUN** (иногда называется *TUN mode*, *Tunnel*, *VPN Adapter* — не обычный «только браузер» / split без TUN).
3. Убедитесь, что VPN подключён, и только после этого запускайте поиск во вкладке **Дропы**.

📷 Скриншот 7: VPN — включён режим TUN

### Если TUN не включён

В логе и в статусе появится ошибка:

> **Semrush недоступен из‑за санкций (Access no longer available для РФ / санкционных территорий). Включите TUN в VPN для получения Outbound Domains**

**Что сделать:** включить TUN в VPN → подождать подключения → снова нажать **Найти дропы**.

📷 Скриншот 8: Ошибка Semrush про санкции и TUN в логе программы

### Если ошибка Yandex Search (режим Яндекс)

В логе может появиться:

> **Yandex Search: нет связи с API (таймаут)…**  
> или раньше: **Yandex Search: fetch failed**

Это значит: программа **не достучалась** до Yandex Cloud (`searchapi.api.cloud.yandex.net`). Ключи при этом могут быть верными.

**Частая причина:** зарубежный VPN с TUN (нужен для Semrush) режет или «ломает» доступ к Yandex Cloud.

**Что сделать:**
1. Сменить сервер VPN на такой, с которого открывается Yandex Cloud, **или**
2. В **Настройках** переключить поиск на **Serper (Google)** — он обычно работает через тот же VPN, что и Semrush, **или**
3. Если VPN с исключениями (split tunnel) — разрешить доступ к `*.api.cloud.yandex.net` напрямую.

📷 Скриншот 8б: Ошибка Yandex Search в логе (fetch failed / таймаут)

## 6. Работа с дропами

### 6.1. Откройте вкладку «Дропы»

В верхнем меню выберите **Дропы**.

📷 Скриншот 9: Вкладка «Дропы»

### 6.2. Введите поисковый запрос

В поле **Поисковый запрос** напишите тему, по которой ищете домены, например:

`курсы дизайна логотипа`

### 6.3. Запустите поиск

Убедитесь, что VPN с **TUN** уже включён (см. раздел 5).

Нажмите кнопку **Найти дропы**.

Программа выполнит цепочку:
1. поиск топ‑5 конкурентов;
2. сбор исходящих доменов (Semrush Outbound — нужен VPN TUN);
3. проверка занятости (WHOIS);
4. получение метрик;
5. разделение на **Good** и **Bad**.

Дождитесь статуса **Готово**. При необходимости нажмите **Стоп**, чтобы прервать процесс.

📷 Скриншот 10: Поиск в процессе (прогресс)

📷 Скриншот 11: Результаты — вкладки Good и Bad

### 6.4. Просмотр результатов

- **Good** — свободные домены (интересны для регистрации).
- **Bad** — занятые / неподходящие.

Клик по домену открывает подробности. При необходимости можно перейти в CheckTrust из карточки домена.

### 6.5. Перенос Good во вкладку скриншотов

Если в Good есть домены и нужно посмотреть их историю:
1. Нажмите **Good → скриншоты**.
2. Программа откроет вкладку **Скриншоты** со списком доменов.

📷 Скриншот 12: Кнопка «Good → скриншоты»

## 7. Скриншоты Wayback Machine

Вкладка **Скриншоты** делает снимки исторических версий сайтов.  
Для скриншотов VPN с TUN **не обязателен** (нужен только для поиска дропов через Semrush).

1. Вставьте список доменов или URL (по одному в строке) — либо перенесите их кнопкой **Good → скриншоты**.
2. При необходимости выберите папку результатов и частоту снимков (параметры также есть в Настройках).
3. Нажмите **Запустить скриншоты**.
4. Дождитесь завершения. Файлы сохранятся в выбранную папку.

📷 Скриншот 13: Вкладка «Скриншоты»

---

## 8. Проверка CheckTrust

Вкладка **CheckTrust** нужна для ручной проверки одного домена по метрикам CheckTrust.

1. Откройте **CheckTrust**.
2. Введите домен.
3. Нажмите **Проверить**.
4. Дождитесь результата (иногда 1–3 минуты, пока сервис считает метрики).

📷 Скриншот 14: Вкладка «CheckTrust»

## 9. Важные замечания

| Тема | Что нужно знать |
|------|------------------|
| Установка | Не нужна — один portable `.exe` |
| Ключи API | Выдаёт руководитель; хранятся только на вашем ПК |
| VPN для дропов | **Обязателен режим TUN** перед «Найти дропы» — иначе Semrush блокирует Outbound |
| Ошибка санкций | Текст: *Semrush недоступен из‑за санкций… Включите TUN в VPN…* |
| Ошибка Yandex Search | *fetch failed* / таймаут — нет связи с Yandex Cloud; смените сервер VPN или используйте **Serper (Google)** |
| Semrush Free | Лимит запросов ограничен; не логиньтесь лишний раз |
| Обновления | Новые версии публикуются на странице Releases по той же ссылке |
