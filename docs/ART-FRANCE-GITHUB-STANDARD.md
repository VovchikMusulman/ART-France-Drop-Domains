# Стандарт GitHub для софта ART France

Единый формат **README** (вкладка Code) и **Release** (вкладка Releases).  
Цель: сотрудник скачивает **один `.exe`**, запускает двойным кликом, без установки Node/Chromium/FFmpeg.

Ориентиры: [Screenshots-of-drops](https://github.com/VovchikMusulman/Screenshots-of-drops), [artfrance-intro](https://github.com/VovchikMusulman/artfrance-intro).

---

## Правила репозитория

1. **Публичный** репозиторий на аккаунте `VovchikMusulman`.
2. В **Releases** — один portable `.exe` (не zip с папкой, не installer, если не оговорено иначе).
3. Имя exe: `ART-France-<Короткое-Имя>.exe` или `ART-France-<Имя>-<версия>-portable.exe`.
4. В git **не** класть: `node_modules/`, `dist/`, `release/`, `.env`, ключи API, пароли, `vendor/`.
5. Язык текстов для сотрудников — **русский**, коротко, без жаргона разработки.
6. About репозитория (GitHub description) — одна строка на английском или русском: что делает софт.

## Шаблон README.md

```markdown
# ART France — <Название продукта>

<1–2 предложения: для чего программа, кому нужна.>

## Для сотрудников

1. Скачайте **`<Имя-файла>.exe`** из [Releases](../../releases)
2. Запустите файл двойным кликом (установка не нужна)
3. <1–3 шага: что сделать в интерфейсе>

<Опционально одной строкой: что уже внутри exe — Chromium / FFmpeg / и т.п.>

## Для разработчиков

```bash
npm install
npm start
```

Сборка portable `.exe`:

```bash
npm run pack
```

Готовый файл: `release/<Имя-файла>.exe`
```

### Требования к README

| Блок | Обязателен | Содержание |
|------|------------|------------|
| Заголовок | да | `ART France — …` |
| Описание | да | зачем софт, 1–2 предложения |
| Для сотрудников | да | скачать → запустить → кратко как пользоваться |
| Для разработчиков | да | install / start / pack + путь к exe |
| Длинные гайды API | нет | только если без этого нельзя запустить |

Не писать в README секреты, длинные changelog и внутренние баги.

## Шаблон текста Release

**Title:** `ART France <Название> vX.Y.Z`  
**Tag:** `vX.Y.Z`  
**Asset:** один файл `.exe`

```markdown
## Что внутри
Портативный `.exe` — установка не нужна. <Если есть runtime внутри — упомянуть: Chromium / FFmpeg и т.п.>

## Как пользоваться
1. Скачайте **`<Имя-файла>.exe`**
2. Запустите двойным кликом
3. <короткий сценарий: 1 действие в UI>

## Возможности
- <пункт 1>
- <пункт 2>
- <пункт 3>
```

Для **обновлений** (v1.0.1+) вместо/дополнительно к «Возможности»:

```markdown
## Что нового
- <изменение 1>
- <изменение 2>
```

Release — короче README: сотрудник должен понять за 15 секунд, какой файл качать и что нажать.

## Сборка portable (для агента)

- Цель: **один** Windows x64 portable exe.
- Команда обычно: `npm run pack` (или `npm run dist` — как в package.json).
- В `electron-builder`: `"target": "portable"`, фиксированный `artifactName`.
- Встроенные браузеры/бинарники — через `extraResources` / vendor, чтобы сотрудник ничего не ставил.
- Перед релизом: собрать exe локально, проверить запуск двойным кликом, залить в GitHub Release.
