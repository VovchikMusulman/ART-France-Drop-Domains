## Что внутри
Портативный `.exe` со встроенным Chromium — ничего дополнительно ставить не нужно.

## Что нового
- CheckTrust: метрики **появляются по мере поступления** (возраст / ИКС), опрос не обрывается на первом куске
- Ждём CheckTrust до ~8 минут; Wayback — только если сервис за это время ничего не отдал
- Частичный ответ показывается сразу, пока приложение продолжает ждать остальные поля

## Как пользоваться
1. Скачайте **ART-France-Drop-Domains.exe**
2. Вкладка **CheckTrust** → домен → **Проверить** (или **Загрузить метрики** у Good)
3. Смотрите правую панель: поля обновляются по ходу; дождитесь окончания ожидания
